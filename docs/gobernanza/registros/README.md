# Registros de decisión de gobernanza

Archivos de decisiones relevantes (aprobación, restricción, rechazo,
autorización de proveedor, validación de INT-*).

- Usar `_plantilla-decision.md`
- Sin PII ni secretos
- Nombrar: `YYYY-MM-DD-<id-componente>-<decision>.md`

La existencia de un registro **no** la inventa el harness.
